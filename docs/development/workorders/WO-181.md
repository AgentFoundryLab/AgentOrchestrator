# WO-181: Adopt the record schema across the distributed package

## Summary

Replace this package's ad-hoc identifier conventions with the typed record schema in every distributed
instruction surface — policy, agent profiles, skills, templates, and workflow docs — so a consuming
repository inherits one artifact model rather than two.

Implementation Plan: [WO-181-implementation-plan.md](WO-181-implementation-plan.md)

## In Scope

- `package/policy/RULES.md`: id grammars, per-type identity fields, controlled vocabularies, status vocabularies
- `package/skills/**`: retarget `spec`, `architect`, `planner`, `validate`, `reconcile`, `status-update`, and sweep the rest
- `package/agents/**`: retarget all nine profiles
- `package/templates/**`: per-record-type templates; retire superseded ones
- `package/workflows/**`, `package/hooks/README.md`, `AGENTS.md`, `docs/INDEX.md`
- `tests/install/smoke.sh` where it asserts a retired template

## Out of Scope

- This repository's own artifacts — `WO-182` owns those
- Building an id allocator; the sole-allocator rule replaces it
- Re-including `factory-cli` or any registry-bound script

## Requirements

| Requirement | In scope here (brief) |
| --- | --- |
| `REQ-002` | The skill interface must stay runtime-portable through the retarget |

| `TR-004` / `TRC-004.2` | Installed artifacts must still conform to each runtime's frontmatter conventions |

## Blueprints

- `FBP-FEAT-002` — Record schema and artifact flow: the model being adopted
- `FBP-FND-007` — Policy and knowledge: the ownership rule that keeps `RULES.md` citing rather than restating
- `FBP-FND-003` — Skill system: the frontmatter contract the sweep must not break

## Test Plan

### Unit Tests

- Every skill's `name` equals its directory name.
- Every frontmatter block parses as YAML and carries `name` and `description`.

### Integration Tests

- Every agent's declared skill resolves to an installed skill; every skill's declared agent resolves to an installed agent.
- No live instruction surface retains a pre-migration id form.

### E2E Tests

- `bash install.sh --check` reports no drift.
- `bash tests/install/smoke.sh` passes all conformance, namespacing, restore, and idempotency cases.
