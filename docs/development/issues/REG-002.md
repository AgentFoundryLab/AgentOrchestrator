## Reported behavior

Reported 2026-02-25. Reproduced verbatim from the original `I-006` record:

- Gemini commands profile emits invalid `.toml` files under `~/.gemini/commands/`
- Gemini CLI `FileCommandLoader` reports parse/validation failures, including:
  - parse failures: `research.toml`, `orchestrate.toml`
  - validation failures: `validate.toml`, `review.toml`, `reflexion.toml`, `reflect.toml`, `plan.toml`, `spec.toml`, `optimize.toml`, `onboard.toml`, `implement.toml`, `hitl.toml`, `document.toml`, `distill.toml`, `design.toml`, `deploy.toml`, `analyse.toml`

## Reproduction and evidence

- Environment: Gemini CLI, global install.
- Steps: run the installer with the Gemini runtime and the commands profile, then start Gemini CLI and observe `FileCommandLoader` output.
- Observed: parse failures on two files, validation failures on fifteen.
- Expected: every emitted `.toml` loads without parse or validation error.

Several named files (`reflexion.toml`, `reflect.toml`, `optimize.toml`, `hitl.toml`, `design.toml`, `plan.toml`) correspond to skills that no longer exist — they were retired during the agent/skill port. The report is preserved verbatim regardless: it records what was observed, and re-emitting the same defect for a renamed skill would be the same defect.
