# ISS-007: SessionStart derives project context but never injects it

## Classification

- Category / scope / type: `bugfix` / `hooks` / `logic`
- Severity: `Medium`
- Root-cause state: `Confirmed`
- Root cause: `inject-context.sh` builds its injected block from the hook payload alone. `PROJECT_NAME` is computed one call earlier in `parse_common` and written into the JSONL logs, but never reaches the block that becomes session context, and no code path reads `docs/knowledge/` at all.

## Status

`Open` — found 2026-08-14 while reconciling the session's findings against `FRD-MEM-001`.

## Links

- Affected requirements: `AC-005.2`, `AC-005.4`
- Related Work Order: none — direct-fix path
- Linked reports: none

## Diagnosis

`AC-005.4` requires `PROJECT_NAME` to be **injected** on `SessionStart`. It is derived correctly —
`hook-utils.sh:27` sanitizes `basename "$CWD"` to alphanumerics and caps it at 32 characters — and it
reaches `session-start.jsonl`, `agent-start.jsonl`, and `agent-stop.jsonl` through `--arg project`.
It does not reach stdout. The injected block emits `session`, `agent`, `type`, and a log path, so the
value exists everywhere except the one place the acceptance criterion names.

`AC-005.2` requires relevant project knowledge to be discoverable at session start. Nothing in the
hook reads `docs/knowledge/`, and no other `SessionStart` path does either. `setup-project.sh`
creates the directory and deploys its README; after that, discovery depends on the agent already
knowing to look.

The two share a cause: the injected block was written against the hook payload's own fields rather
than against the acceptance criteria, so every value that had to be derived or read from the
repository was omitted.

Scope note: hooks install only with `--hooks`, and only on Claude Code. That limits blast radius, not
correctness — `AC-005.2` and `AC-005.4` name `SessionStart`, and `SessionStart` is a hook.

## Remediation

Extend the `SessionStart` branch of `inject-context.sh` to emit `PROJECT_NAME` and a bounded index of
`docs/knowledge/`. Keep the `SubagentStart` branch lean: a sub-agent inherits its parent's context,
and re-injecting the same block per spawn pays the cost on every delegation.

Verify by driving the hook with a synthetic payload and asserting both values appear in stdout.
