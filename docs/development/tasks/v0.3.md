### T-101: Add `--subagents` and `--experimental` flags to installer
**Milestone**: v0.3
**Depends on**: T-115, T-116 (installer modularization complete)
**AC**:
- `install.sh --help` lists `--subagents` and `--experimental` flags with descriptions
- `--subagents` gates all subagent artifact install steps; without it no subagent files are written
- `--experimental` enables runtime-specific experimental flags (no-op without `--subagents`)
- Unknown flag combination emits a clear warning and exits non-zero

---

### T-102: Install Claude subagent `.md` files to `.claude/agents/`
**Milestone**: v0.3
**Depends on**: T-101
**AC**:
- All agent `.md` files from `package/agents/` are written to `.claude/agents/` (project mode) or `~/.claude/agents/` (global mode)
- Files are not written if `--subagents` is absent
- Idempotent: re-running does not create duplicates
- `--uninstall` removes only files installed by this path

### T-103: Inject `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` into settings.json env block
**Milestone**: v0.3
**Depends on**: T-101
**AC**:

## v0.3: Installer Modularization

### T-115: Split install.sh into runtime-scoped modules + main dispatcher
**Milestone**: v0.3
**Depends on**: v0.2.0 complete
**AC**:
- `install.sh` refactored into: `install/main.sh` (dispatcher), `install/runtimes/claude.sh`, `install/runtimes/codex.sh`, `install/runtimes/gemini.sh`, `install/runtimes/opencode.sh`, `install/runtimes/qwen.sh`
- Each runtime module is self-contained: no function calls into sibling runtime modules
- All existing tests pass against the refactored layout
- Entry point `install.sh` remains as a thin shim delegating to `install/main.sh`

---

### T-116: Extract shared installer library (transforms, validation, utils)
**Milestone**: v0.3
**Depends on**: T-115
**AC**:
- Shared functions extracted into `install/lib/transforms.sh`, `install/lib/validation.sh`, `install/lib/utils.sh`
- No duplicated logic between runtime modules; all shared logic lives in `install/lib/`
- Runtime modules source only `install/lib/` dependencies, not each other
- All existing tests pass
